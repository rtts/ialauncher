Download IA Launcher

Windows

Click here to download the Windows installer, then double-click the file to run it. This will install IA Launcher for your current user, so there are no administrator privileges required.

GNU/Linux

Open a terminal and execute the following command: 

    pip3 install ialauncher
This will install IA Launcher from PyPI, but be warned: this will get you a rather old version. To get a more modern version, use the Windows installer above (it works in Wine too!), or build it yourself from source (see below).

You can now start IA Launcher with: 

    ialauncher
There is on-line help included. To see it, run: 
    ialauncher --help
